# Hunk Fix

Hunkのユーザーコメントをコード変更へ反映し、検証結果をHunkへ返す。

Hunkの基本操作やコマンド仕様はこのSkillに重複して記載しない。必ず次のコマンドで公式Skillのパスを取得し、そこに記載された操作方法を参照する。

```sh
hunk skill path
```

## Workflow

1. 現在の作業ディレクトリに紐づくHunkセッションを選ぶ。複数候補があり一意に決まらなければ、focus・terminalなどを示して確認する。
2. 選択したセッションからユーザーコメント、対象差分、必要なコンテキストを取得する。対応済みのコメントは繰り返さない。
3. コメントの意図と周辺コードを確認し、曖昧な依頼は変更前に確認する。
4. ユーザーの既存変更を保持し、コメントに必要な範囲だけ修正する。削除・設定変更・外部操作など影響の大きい変更は、コメントが明確に求める場合だけ行う。
5. 変更に応じた最小限の検証を行う。検証手段がなければ、実施した手動確認を報告する。
6. 対象hunkが残っていれば、対応内容と検証結果をagentコメントで返す。削除や大幅な変更で対象hunkが消えた場合は、別ファイルへ代替コメントを付けず、最終応答で報告する。
