# Hunk Comment

これまでの修正とコンテキストをもとに、変更の意図や注意点をHunkへagent noteとして付与する。

Hunkの基本操作やコマンド仕様はこのSkillに重複して記載しない。必ず次のコマンドで公式Skillのパスを取得し、そこに記載された操作方法を参照する。

```sh
hunk skill path
```

## Workflow

1. 現在の作業ディレクトリに紐づくHunkセッションを選ぶ。複数候補があり一意に決まらなければ確認し、セッションがなければHunkを起動してもらう。
2. 選択したセッションから差分、既存コメント、必要なコンテキストを取得する。対応済みのコメントや既存noteは繰り返さない。
3. 変更の意図、判断理由、影響、検証結果など、差分だけでは分かりにくい情報を整理する。参考にした公式ドキュメントやIssueなどのリンクがあれば、noteに積極的に含める。
4. 対象hunkへ移動し、必要な箇所に `hunk session comment add` または `comment apply --stdin` でagent noteを付与する。必要ならhighlightも使う。
5. 付与したnoteと未解決の確認事項を確認し、対応内容を簡潔な箇条書きでユーザーへ報告する。

コード変更、コミット、push、PR作成は行わない。対象hunkがなくなっている場合は、別ファイルへ代替noteを付けず、その理由を報告する。
